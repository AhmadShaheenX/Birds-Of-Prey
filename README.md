# Birds_Of_Prey_Simulator
COMP9001 Final Project

'Birds of Prey' is an interactive survival game developed in Python, played through text.
Users can select from three different Australian Raptors, each equipped with their own sets of skills!
Through turn-based roleplay, the user will feel a real sense of freedom and consequences directed at each of their decisions.

As a predator, you'll be able to hunt, train, access logs and duel with an opponent!

How to Play:
1. Make sure you have Python installed on your computer.
2. Download 'birds_of_prey.py'
3. Run the script and simply start!
